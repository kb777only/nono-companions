# Version 0.4 — parachuting

After 650 ms continuously airborne, a released character enters PARACHUTING and switches from the falling pose to a two-frame glide loop. Each spouse has their own timer and a generated canopy matching their outfit: cream/sage dinosaur for the husband, plum/lavender heart for the wife. The cap is 0.85 character-heights per second along the current gravity direction (about 88 dp/s at the normal size). Crosswind velocity is damped. A short fall that lands before 650 ms does not deploy.

Dragging does not advance the fall timer. Re-grabbing closes that character’s canopy; the other character continues their own fall/glide. Landing closes the canopy, plays landing recovery and resets the timer. Screen-off and display changes clean up transient fall state. The canopy uses a separate pass-through window, with cords drawn toward the raised hands; the pet touch rectangle stays 72×104 dp. Two overlapping canopy windows have combined opacity below Android’s touch-obscuring threshold; speech is suppressed during parachuting to avoid stacking an extra pass-through window there.

The canopy remains visually above the upright character while the motion follows screen-plane gravity. Exact cord alignment at screen edges and sideways glide artwork need a phone visual check. The phone was disconnected for this release, so no device test or installation is claimed.
